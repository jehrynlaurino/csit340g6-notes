# CSIT340 G6 Notes App

React Notes App for Labs 5 and 6 by Jehryn D. Laurino.

## Run locally

Use Node.js 22.12 or newer. Install dependencies with `npm install`, then run `npm run dev` and open the local URL printed in the terminal. On Windows PowerShell, use `npm.cmd` if script execution policy blocks `npm`.

## Check the project

- `npm run lint`
- `npm run build`
- `npm run preview` to preview the production build

The lab milestones are recorded in order in Git history. Lab 6 continues in this same repository after the empty `chore: start lab 6` commit.
